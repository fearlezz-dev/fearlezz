Questions

Does the free CLI ever call home?

No. Only fearlezz run --ci --publish uploads, and only when you add it.

What if we stop paying?

Proof keeps working. Links turn read only, then expire with retention.

Download every bundle and approval as JSON first. They are yours.

Why not charge per picture, like other tools?

Per picture bills punish good coverage. Films would cost 25 times more.

We want you to record more, not less.

Is open source free?

Yes. Public repositories get the Public plan. Ask for Team for free if you need private links.
